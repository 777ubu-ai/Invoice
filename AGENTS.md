# AI agent instructions

## Экономный режим AI

По умолчанию отвечать владельцу кратко: результат → ключевой факт → следующий шаг.
Не повторять вопрос, не писать вводную воду, не перечислять очевидное.

Никогда не сокращать доказательства: сохранять PASS/FAIL, commit SHA, версии,
устройства, точные ошибки, риски, release blockers и фактические результаты тестов.

Для security, необратимых действий, production/release, сложного debugging и
архитектурных изменений давать столько деталей, сколько нужно для безопасного решения.

Пользовательские и маркетинговые тексты писать естественно: без шаблонного
AI-пафоса, повторов и выдуманных фактов. Код, SQL, JSON, API-контракты, команды,
логи и тестовые результаты не переписывать ради "красоты".

Если владелец просит подробнее — дать полный разбор, затем вернуться к краткому режиму.
Не подключать большие внешние skills только ради краткости или "humanize", если эти
правила уже покрывают задачу.
