# Packing Invoice

Отвечать владельцу кратко и по-русски. Не сокращать фактические результаты проверок.
Два Telegram-бота, общая PostgreSQL, общий серверный контроль доступа.
Бухгалтер работает только в Invoice Bot; руководитель — в обоих ботах.
Нельзя подменять договорную стоимость таможенной или автоматически включать ТПиН в инвойс.
Не угадывать ставки, коды, вес нетто, цены или курсы. Неполные расчёты не считать готовыми.
Не возвращать фиктивные данные при сбое. Не выдавать запланированные функции за работающие.
Изменения согласованных исходных данных требуют новой версии и повторного согласования.
Не запускать старые миграции, не удалять рабочую БД и файлы при обновлении кода.
Проверки перед сдачей: npm run typecheck, npm test, npm run build.
