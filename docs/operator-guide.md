# Инструкция оператора TNVED.ai bot

## Начало работы

1. Найди бота `@InvoiceAgentsBot` в Telegram.
2. Отправь `/start`. Если ты ещё не в системе — бот попросит обратиться к
   руководителю.
3. Руководитель добавит тебя командой `/add_operator`, после чего повтори
   `/start`.

## Создание инвойса

1. `/new` — бот спросит клиента.
2. Пришли packing list файлом (xlsx, pdf или фото).
3. Выбери режим стоимости:
   - **Целевые платежи $** — задашь сумму, бот посчитает обратно.
   - **Цена за кг** — задашь $/кг.
   - **Прайс клиента** или **Индикатив КГД** — без ввода.
4. Бот покажет прогресс. Через 2–3 минуты пришлёт сводку.
5. Если есть позиции на ревью — кнопка «👁 Посмотреть #N», выбери код или
   оставь текущий.
6. Кнопка «✅ Одобрить» — бот вернёт `.xlsx` инвойс.

## Полезные команды

| Команда | Что делает |
|---|---|
| `/menu` | Главное меню |
| `/list` | Мои активные задачи |
| `/history` | Завершённые инвойсы |
| `/clients` | Доступные клиенты |
| `/help_manager` | Запрос помощи руководителю |
| `/cancel` | Сбросить текущий диалог |
| `/me` | Моя статистика |

## Если что-то пошло не так

- Бот не понимает — `/help` покажет список команд.
- Завис в диалоге — `/cancel`.
- Получил ошибку «классификация не удалась» — `/new` ещё раз; если повторяется
  — `/help_manager`.
